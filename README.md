# 🛍️ Retail Sales Analysis Dashboard

## 📌 Project Overview

The **Retail Sales Analysis Dashboard** is an end-to-end data analytics project that transforms raw retail sales data into meaningful business insights using **MySQL** and **Microsoft Excel/WPS Office**.

The project follows a complete data analysis workflow, including data import, database normalization, SQL analysis, and interactive dashboard creation. It enables users to monitor key business metrics, analyze sales performance, identify top-performing products and customers, and make data-driven decisions through intuitive visualizations and interactive filters.

---

## 🚀 Features

* Designed a normalized retail database using MySQL.
* Performed data cleaning and business analysis with SQL.
* Created SQL Views for reusable reporting.
* Built an interactive dashboard using Pivot Tables and Pivot Charts.
* Added KPI Cards to monitor key business metrics.
* Included interactive slicers for Region and Category filtering.
* Presented sales trends and business performance through clear visualizations.
