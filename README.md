Overview:
  This project demonstrates an end-to-end Retail Sales Analysis workflow using MySQL and Microsoft Excel/WPS Spreadsheet. The objective is to transform raw retail sales data into meaningful business insights through SQL analysis and an interactive dashboard.
The project covers the complete data analysis process, including data import, database design, SQL querying, KPI generation, and dashboard visualization.

Objectives:
1.Import and manage retail sales data in MySQL.
2.Design a normalized database using multiple related tables.
3.Perform business analysis using SQL queries.
4.Create reusable SQL Views for reporting.
5.Build an interactive dashboard using Pivot Tables, Pivot Charts, and Slicers.
6.Present key business metrics in a simple and visually appealing format.

Tools & Technologies:
1.MySQL Workbench
2.SQL
3.Microsoft Excel 365
4.Pivot Tables
5.Pivot Charts
6.Slicers
